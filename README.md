# js-todo

A small vanilla JavaScript todo list app, a classic frontend exercise.

## About

Browser todo list with add, check-off and remove, no framework, no build
step. Built in July 2021.

## Features

- Add a task with the input field
- Click a task to mark it done
- Remove a task with the close button

## Tech stack

- HTML, CSS, vanilla JavaScript (inline script)

## Getting started

Open `index.html` directly in a browser, no build or install needed.

## Status

Learning project, not maintained.
